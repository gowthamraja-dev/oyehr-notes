My approvals — one page for every request

Reference only. The build keeps the existing My approvals UI (task 331); this mockup is not the implementation target.

Showcase only (static mockup, no backend). It shows what changes before any code is written: the Regularization Inbox is removed, and Leave, Work from home, Regularization and Shift change requests are approved from My approvals, next to expense claims.

Try it: (1) click the eye on a row to see the reason and key details without opening Review; (2) Review opens the drawer, where the reason sits at the top with the organisation's approval steps; (3) switch Viewing as between Admin and HR Manager: Work from home has no workflow set in this sample organisation, so its rows can't be decided and the Admin is sent to Approval Setup while the HR Manager is told to ask the Admin; (4) Approve and Reject (reason required) work inline on the other rows.
