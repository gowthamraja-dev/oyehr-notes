## Scope
The new table only. No resolver, service or API change (254+). No change to any existing table.

Columns of `shift_day_overrides` (model `ShiftDayOverride`, file `shift_day_override.py`):
- `id` BigInteger pk
- `care_delivery_program_master_id` BigInteger, FK `care_delivery_program_masters.id`, NOT NULL
- `shift_master_id` BigInteger, FK `shift_masters.id`, **nullable** (NULL = every shift in the CDP)
- `override_date` Date NOT NULL
- `day_type` String(10) NOT NULL — `'WeekOff'` | `'Working'`
- `reason` String(255) NOT NULL
- `recalc_status` String(10) NOT NULL, `server_default=text("'Pending'")` — `Pending|Running|Done|Failed`
- `recalculated_at` DateTime(timezone=True) nullable
- `recalc_result` JSONB nullable (`Mapped[Any | None]`)
- `is_active` Boolean `server_default=text("true")`; `archive` Boolean `server_default=text("false")`
- `archived_by_id` BigInteger nullable; `archived_at` DateTime(tz) nullable
- `created_by_id`, `updated_by_id` BigInteger nullable
- `created_at` `server_default=func.now()`; `updated_at` `server_default=func.now()`, `onupdate=func.now()`

Indexes (names are part of the contract):
- `ix_shift_day_overrides_cdp_date` on `(care_delivery_program_master_id, override_date)`
- unique `uq_shift_day_overrides_org_wide` on `(care_delivery_program_master_id, override_date)` `WHERE shift_master_id IS NULL AND archive = false`
- unique `uq_shift_day_overrides_shift` on `(care_delivery_program_master_id, shift_master_id, override_date)` `WHERE shift_master_id IS NOT NULL AND archive = false`
- `ix_shift_day_overrides_recalc_queue` on `(care_delivery_program_master_id, recalc_status)` `WHERE recalc_status IN ('Pending','Running','Failed')`
- CHECK `ck_shift_day_overrides_day_type` (`day_type IN ('WeekOff','Working')`) and `ck_shift_day_overrides_recalc_status`.
Use `Index(..., unique=True, postgresql_where=text(...))` in `__table_args__`.
